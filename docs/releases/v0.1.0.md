# PinchDial 0.1.0

First downloadable release of PinchDial. Turn a dial that sends keyboard keys into smooth pinch-to-zoom on macOS.

## Download and install

Download **PinchDial.dmg** from Assets below to install.

Grant **Accessibility** in PinchDial's Setup window, and **Input Monitoring** if needed. If macOS blocks the app, choose **System Settings → Privacy & Security → Open Anyway**.

Requires **macOS 13+**. Supports **Apple Silicon and Intel**.

## Features

- Smooth dial zooming with adjustable sensitivity.
- Custom single-key zoom shortcuts and continuous zoom while holding a key.
- Launch at Login and optional menu bar icon.

## Distribution and compatibility

Locally signed for personal use; **not notarized by Apple**. Zoom behavior may vary by app and macOS version.
