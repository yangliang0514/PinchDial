# PinchDial 0.1.0

First downloadable release of PinchDial. Turn a dial that sends keyboard keys into smooth pinch-to-zoom on macOS.

## Download and install

Download **PinchDial.dmg** under Assets below (the source-code archives are for development).

1. Open the DMG and drag **PinchDial** into **Applications**.
2. Eject the DMG and open PinchDial from Applications.
3. If macOS blocks it, choose **System Settings → Privacy & Security → Open Anyway**, then confirm Open.
4. Grant **Accessibility** in PinchDial's Setup window. Grant **Input Monitoring** if input is unavailable, then quit and reopen if prompted.
5. Configure your dial to send **F18** for zoom in and **F19** for zoom out, or assign your own single-key shortcuts.

Requires **macOS 13 Ventura or later**. Includes native **Apple Silicon and Intel** builds. No Xcode or build tools are required to install.

## Features

- Smooth dial zooming with adjustable sensitivity.
- Custom single-key zoom shortcuts and continuous zoom while holding a key.
- Launch at Login and optional menu bar icon.

## Distribution and compatibility

This personal-use build is signed with a persistent local certificate, not an Apple Developer ID, and is **not notarized**. Expect a first-launch security override. You do not need to install or trust the signing certificate on another Mac. Organization-managed Macs may restrict opening locally signed apps.

The gesture backend uses undocumented macOS event fields. Behavior varies by application and macOS version; test it with the apps and dial you use. Accessibility and Input Monitoring permissions must be granted separately on each Mac.

To update, quit PinchDial and replace the copy in Applications. Approve permissions again if macOS requests them.

`PinchDial.dmg.sha256` contains the SHA-256 checksum for the disk image.
